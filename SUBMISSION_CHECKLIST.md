# Before submitting

- [ ] Install dependencies successfully.
- [ ] Run `python manage.py check`.
- [ ] Run `python manage.py migrate`.
- [ ] Run `python manage.py test`.
- [ ] Start server and test all routes in Postman.
- [ ] Test that a second user cannot view or change the first user's patients.
- [ ] Test duplicate patient-doctor assignment returns a validation error.
- [ ] Configure PostgreSQL using `.env` before final submission.
- [ ] Push the project to GitHub and email the repository link in the existing thread.
